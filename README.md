## 🚀 كيف ترفع الموقع على GitHub Pages (مجانًا)

1. أنشئ حسابًا على [github.com](https://github.com) إذا لم يكن لديك.
2. اضغط **+** ثم **New repository** — سمّه: `saleh-premium` واجعله **Public**.
3. ارفع **كل محتويات هذا المجلد** من صفحة المستودع: **Add file → Upload files** ثم **Commit changes**.
4. من **Settings → Pages**: اختر Source = `Deploy from a branch`، و Branch = `main` + `/ (root)` ثم **Save**.
5. بعد دقيقة أو دقيقتين سيصبح موقعك على:

   `https://اسم-حسابك.github.io/saleh-premium/`

## 🔗 خطوة مهمة بعد الرفع: تحديث رمز QR

رمز QR في صفحة «اتصل بنا» يُبنى تلقائيًا من الرابط المخزّن في:

```
js/config.js
```

غيّر السطر:

```js
siteUrl: "https://YOUR-USERNAME.github.io/saleh-premium/",
```

وضع مكانه رابطك الحقيقي، ثم ارفع الملف مرة أخرى وامسح الرمز بجوالك للتأكد.

> 💡 عند طباعة فلايرات جديدة، يمكنك تصوير رمز QR من صفحة اتصل بنا واستخدامه مباشرة.

## 🛒 سلة الطلب والطلب عبر واتساب

- في صفحات المنتجات والعروض: زر **«أضف إلى السلة»** بجانب كل منتج ورائحة وصندوق.
- زر السلة العائم (أسفل يسار الشاشة) يفتح لوحة السلة: تعديل الكميات، الحذف، وإدخال الاسم والولاية وملاحظات (اختياري).
- زر **«إتمام الطلب عبر واتساب»** يحوّل السلة إلى رسالة مرتبة (الأسماء + الكميات + الاسم + الولاية) ويفتح واتساب جاهزة للإرسال إلى 0669103856.
- السلة محفوظة في متصفح الزبون (localStorage) — تبقى حتى لو أغلق الصفحة أو تنقل بين الصفحات.
- كل المنطق في `js/cart.js` + التنسيقات في نهاية `css/style.css` — بدون أي خادم أو خدمات خارجية.
